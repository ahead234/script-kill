# 已知限制

1. V1.0 为单门店系统，不支持多门店数据隔离。
2. 不接入支付、短信、微信登录、第三方票务或消息推送。
3. 拼场允许单人起约；是否达到开本最少人数由门店人工确认，没有定时自动成团或解散任务。
4. 场次状态由管理人员维护，没有后台调度器按时间自动从 `OPEN` 切换为 `IN_PROGRESS/COMPLETED`。
5. 玩家只能修改 `PENDING` 评价；已发布或隐藏评价不能再次编辑。
6. V1.0 用户管理只提供查询与启停，不提供在线新增用户、角色分配和密码重置。
7. 封面仅保存相对路径，未实现文件上传、图片裁剪和对象存储。
8. 数据库连接使用 `DriverManager`，教学规模足够；生产环境应改用 Tomcat JNDI DataSource/连接池。
9. 未实现登录失败次数限制、验证码和“记住我”；生产环境还应由反向代理启用 HTTPS 与 Secure Cookie。
10. 操作日志保留在数据库中，未实现归档、导出和防篡改存储。
11. 当前开发环境的 MySQL root 账号需要未知密码，未执行数据库集成、并发预约和浏览器端到端测试；详见 `test-report.md`。
12. 未生成项目运行截图。必须在实际部署、初始化数据库并运行页面后截图，不能以参考站点或静态稿替代。
